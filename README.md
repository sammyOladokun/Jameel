# Jameel storefront

A responsive React + TypeScript jewelry storefront built with Vite. The landing page includes a luxury hero, service promises, brand benefits, shopping steps, a filterable featured collection, customer reviews, and footer navigation.

## Getting started

```sh
npm install
npm run dev
```

## Project layout

- `src/App.tsx` — storefront sections and collection interactions
- `src/styles.css` — responsive dark luxury theme
- `index.html` — page metadata and entry point

Product and hero photography currently use Unsplash image URLs. Replace these with Jameel's approved product and campaign photography before launch.

Build for production with `npm run build`, then serve the generated `dist/` directory with your preferred static host.
